# Design — 个人网站设计说明

## 1. 页面区块与浏览顺序

1. **Hero** — 首屏显示姓名和定位，吸引注意
2. **About** — 个人简介 + 头像
3. **Skills** — 技能展示（两个分类陈列）
4. **Projects** — 项目卡片，含报告链接
5. **Footer** — GitHub 社交链接

## 2. 视觉风格

### 颜色
- 主色：#477dca（蓝色，用于按钮和链接）
- 背景：白色
- 文字：#333（深灰色）
- 区块分隔：浅灰色边框

### 字体
- Roboto（Google Fonts），清晰现代

### 整体风格
简洁、专业、以内容为主，不过度装饰

## 3. 响应式要求

### 桌面端（≥768px）
- 两栏布局：左侧头像 + 简介，右侧详细内容
- 项目卡片完整显示

### 手机端（<768px）
- 单栏布局，内容从上到下排列
- 导航折叠为汉堡菜单
- 字体和间距自适应

## 4. 文件结构

| 文件/目录 | 说明 |
|---|---|
| _config.yml | 所有个人信息和内容配置 |
| index.md | 入口文件，引用默认布局 |
| images/ | 头像和图片资源 |
| projects/ | 项目详情页 |
| _sass/base.scss | 自定义样式（蓝色按钮） |
| docs/ | 项目文档 |
| screenshots/ | 验收截图 |
| 其余文件 | 模板系统文件，不做修改 |

## 5. 模板使用

- 使用 Modern Resume Theme（sproogen/modern-resume-theme）
- 保留模板布局和样式系统
- 修改内容配置、头像和个人信息
- 添加了自定义按钮样式
