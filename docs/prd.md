# PRD — 个人网站项目

## 1. 项目定位

### 目标访问者
潜在雇主、课程教师、同学。他们最先寻找的信息是：我是谁、我学什么、我会什么、我做过什么。

### 希望访问者记住什么
我是一个对数据分析与金融科技有热情的学习者，具备使用 AI 工具解决实际问题的能力。

## 2. 本期内容范围

### 必须包含
- Hero（姓名 + 职业定位）
- About（个人简介）
- Skills（数据分析与建模、AI与大模型应用）
- Projects（金融资产收益率的探索性数据分析）
- Contact（GitHub 链接）

### 明确不涉及（不做事项）
- ❌ 不要求从零编写全部 HTML、CSS 或 JavaScript
- ❌ 不要求加入登录、数据库、支付、复杂后台或访客追踪
- ❌ 不要求选择复杂框架；复杂模板不会自动获得额外分数
- ❌ 不要求公开私人手机号、住址、身份证件或其他敏感信息
- ❌ 不制作动画、特效或花哨的视觉展示
- ❌ 不引入无关依赖或不更换框架

## 3. 完成标准

- GitHub Pages 可公开访问
- 五个基础区块齐全，内容真实
- 桌面端与手机端均可正常浏览
- 项目链接可点击查看完整报告
- 仓库含 PRD / Design / Checklist 文档
- 至少 3 次有意义的 Git Commit

## 4. 隐私边界

- ❌ 不公开课程邀请码、个人密码、API Key、Token
- ❌ 不公开手机号、住址或其他个人敏感信息
- ❌ 不提交 .env 文件或依赖目录
- ✅ 仓库保持 Public，便于教师验收
- ✅ 内容真实性由本人负责

## 5. 验收方式

- 逐项对照 Checklist 验收
- 截图保留证据
- 同伴互换检查
