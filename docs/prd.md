# PRD — 个人网站项目

## 1. 项目定位

### 目标访问者
潜在雇主、课程教师、同学。他们最先寻找的信息是：我是谁、我学什么、我会什么、我做过什么。

### 希望访问者记住什么
我是一个对数据分析与金融科技有热情的学习者，具备使用 AI 工具解决实际问题的能力。

## 2. 本期内容范围

### 必须包含
- Hero（姓名 + 职业定位）
- About（个人简介）
- Skills（数据分析与建模、AI与大模型应用）
- Projects（金融资产收益率的探索性数据分析）
- Contact（GitHub 链接）

### 明确不包含
- 登录、数据库、支付、后台系统
- 访客追踪与分析
- 复杂框架（保留 Jekyll 静态生成）
- 私人手机号、住址、身份证件

## 3. 完成标准

- GitHub Pages 可公开访问
- 五个基础区块齐全，内容真实
- 桌面端与手机端均可正常浏览
- 项目链接可点击查看完整报告
- 仓库含 PRD / Design / Checklist 文档
- 至少 3 次有意义的 Git Commit

## 4. 隐私边界

- 不公开课程邀请码、个人密码、API Key、Token
- 不公开手机号、住址等敏感信息
- 仓库保持 Public，便于教师验收
