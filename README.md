# 潘科旭 - 个人网站

基于 Modern Resume Theme 构建的个人简历网站，部署于 GitHub Pages。

## 访问地址

https://lthercheese.github.io/Personal-Website/

## 所用模板

- **模板**: [Modern Resume Theme](https://github.com/sproogen/modern-resume-theme)
- **作者**: James Grant (sproogen)

## 主要修改

- 替换为个人真实信息（姓名、简介、技能、项目）
- 添加头像图片
- 添加金融分析项目页面（R Markdown 报告）
- 自定义项目链接按钮样式（蓝色）
- 修复 CI 工作流中的 Actions 版本过时问题
- 修复模板 a.html 中相对链接的处理

## 网站内容

- **Hero**: 姓名 + 职业定位
- **About**: 个人简介
- **Skills**: 数据分析与建模、AI与大模型应用
- **Projects**: 金融资产收益率的探索性数据分析
- **Contact**: GitHub 主页链接
